VPN热点共享

ShareHotspotVPN · 作者 zhuifeng

将本机的 Wi-Fi、蜂窝移动数据或 Shadowrocket（小火箭）等 VPN 通过 iOS 个人热点共享给周围设备，五种模式一键切换，连上热点即刻上网，客户端零配置。

连上热点即可走本机 VPN 或 Wi-Fi，连接设备无需任何代理配置。
🛫 不插卡、不开蜂窝、飞行模式照样共享

没插 SIM 卡（备用机、无卡激活的设备）、关闭蜂窝数据、甚至直接打开飞行模式，都能把本机 Wi-Fi 或 Wi-Fi + VPN 共享出去。

以前 iOS 的个人热点必须依赖蜂窝网络才能开启，没卡就整条路走不通。现在这个限制被彻底绕开了：只要连着 Wi-Fi，哪怕全程飞行模式，热点一样能开，其他设备照样上网。

设置页实时展示运行状态、热点 / Wi-Fi / VPN 接口与转发统计
控制中心长按，直接切换五种共享模式

🆓 免费使用

本插件完全免费，无内购、无激活门槛、无功能限制，可自由安装使用。

✨ 核心功能

  • 无卡 / 飞行模式可用：不插 SIM 卡、关闭蜂窝数据或开启飞行模式，依然能共享本机 Wi-Fi 与 Wi-Fi + VPN，个人热点不再依赖蜂窝网络。
  • 五种共享模式：自动、仅共享 Wi-Fi、仅共享数据、Wi-Fi + VPN、数据 + VPN，按当前网络自动切换或强制指定，热点设备全程零配置。
  • Wi-Fi 也能共享：不只是共享 VPN，还能把本机当前连接的 Wi-Fi 直接分给热点设备；共享 Wi-Fi 时状态栏保留 Wi-Fi 图标。
  • 全协议透明转发：支持 TCP 透明转发、DNS 劫持转发（完美适配 Fake-IP 分流规则），以及可选 UDP 转发（支持语音、游戏与 QUIC；若节点不支持 UDP，可一键关闭自动回落至 TCP）。
  • 防闪断保活：内置一键放宽 VPN 内存上限（提升至 256MB），并对热点服务做了优先级保护，有效避免大流量或多设备并发时热点或 VPN 进程被杀后台。
  • 状态一目了然：设置页实时展示当前状态、个人热点、Wi-Fi 接口（含本机 IP）、VPN 接口及 TCP / DNS / UDP 转发统计。
  • 运行日志与诊断导出：内置轻量运行日志，设置内可直接查看，并一键导出诊断状态与偏好配置（UTF-8 JSON），反馈问题时快速提供现场信息。

🎛️ 五种共享模式

  • 自动（推荐）：根据当前网络自动切换——仅连 Wi-Fi 时共享 Wi-Fi；仅用移动数据时共享移动数据；移动数据 + VPN 时共享数据 VPN；Wi-Fi + VPN 时自动叠加共享（经 Wi-Fi 再走 VPN）。
  • 仅共享 Wi-Fi：强制共享本机 Wi-Fi（即使开启 VPN 也直走 Wi-Fi），状态栏保持显示 Wi-Fi；未连 Wi-Fi 时待机。
  • 仅共享数据：强制走系统蜂窝移动数据直通（不经插件代理或 VPN）。
  • Wi-Fi + VPN：强制叠加共享（本机与热点均经 Wi-Fi 走 VPN），状态栏保持显示 Wi-Fi；Wi-Fi 或 VPN 未连接时待机。
  • 数据 + VPN：强制经蜂窝移动数据走 VPN（即使连着 Wi-Fi 也切回移动数据）；VPN 未连接时待机。

共享 Wi-Fi 时无需开启蜂窝数据，不插卡、开飞行模式同样能用，实际流量全程走 Wi-Fi，不消耗手机流量。若其他设备搜不到热点，建议在系统「个人热点」中打开「最大兼容性」。

⚡ 简便易用

  • 控制中心轻点开关：自带控制中心快捷模块（依赖 CCSupport），轻点即启停插件，并与系统设置页实时同步。
  • 控制中心长按切模式：长按模块弹出菜单，直接选择五种共享模式，无需进设置；图标与颜色会随当前模式自动变化。
  • 与个人热点联动：打开「开启热点共享」（或轻点控制中心开关）时自动开启系统「个人热点」，关闭时一并关闭；若蜂窝数据未开启导致热点打不开，会弹出提示。

🛡️ 安全与隐私

  • 防 IPv6 泄露：默认拦截热点侧非链路本地 IPv6 流量，防止设备绕过 VPN 直连运营商网络造成真实 IP 泄露。
  • 纯本地运行、无痕清理：基于系统原生 PF 防火墙与本地轻量转发引擎实现，不经过任何第三方服务器、不收集任何数据、无后台日志写入；关闭开关或卸载插件时自动清除全部规则，不残留任何系统网络修改。

🔋 省电

  • 纯事件驱动架构：采用 SCDynamicStore 系统网络事件监听与 kqueue 异步多路复用，拒绝后台空转轮询。
  • 智能待机休眠：未开启共享或未同时满足“热点 + VPN”条件时自动进入零负载待机；无活跃连接时自动停用定时清理器，日常几乎零额外耗电。

📱 系统与越狱兼容

  • 系统版本：支持 iOS 15.0 及以上（兼容 iOS 15 / iOS 16 / iOS 17）。
  • 越狱环境：原生支持多巴胺（Dopamine）等 Rootless（arm64 / arm64e）与 RootHide（arm64e）双环境，覆盖全系越狱机型。
